# metadata/ — what stays here vs. what goes to LUNARC

This directory holds only small reference/code-structure tables that define
what a code *means* — nothing generated by the pipeline, and nothing cached
from an external source, lives here. Rule of thumb: if a script writes it,
or downloads/caches a multi-MB external source file, it's data, not
metadata, and belongs on LUNARC nobackup storage instead (see
`src/latent_industry/common/paths.py`'s `RAW_DATA_DIR` / `PROCESSED_DATA_DIR`
/ `EMBEDDING_DIR`, all under
`/lunarc/nobackup/projects/lu2025-17-39/DataLatentIndustryRepresentations/`).

## What's here (git-tracked, ~400KB)

- `mapping_Sni_{2,3,4,5}digits_{1992,2002,2007}.json`, `mapping_Sni_section_{...}.json`
  — SNI code → description lookups per digit-level and version.
- `mapping_02_07.csv`, `mapping_92_02.csv` — SCB cross-version code crosswalks.
- `mapping_Municipality.json` — canonical 290-code municipality universe and
  names.
- `municipality_crosswalk.json` — year-sensitive SCB-sourced mappings from
  historical municipality codes to the canonical universe, formation years
  for municipalities created during 1990–2019, and invalid-code handling.
  `src/latent_industry/common/municipalities.py` loads and validates it.

## What moved to LUNARC (as of 2026-07-20)

- `<LUNARC_DATA_ROOT>/raw/nace/` — `NACE_Rev2_descriptions_only.pdf` (source
  PDF for `build_nace_taxonomy.py`) and `en-sni{1992,2002,2007}.xlsx` (SCB/
  Eurostat classification handbooks, currently unused by any script — kept
  as candidate source material for TODO.md §2's native pre-07 description
  text investigation).
- `<LUNARC_DATA_ROOT>/raw/io/` — cached external IO source tables
  (`nrio_siot.xlsx`, Eurostat/WIOD extracts, code reference/codelist csvs),
  downloaded/cached by `build_input_output_relatedness.py`.
- `<LUNARC_DATA_ROOT>/raw/shape_files/` — municipality GIS shapefiles used
  by `P04_growth.py` for mapping.
- `<LUNARC_DATA_ROOT>/raw/downstream_outcomes/` — default output dir for
  `download_regional_outcomes.py`.
- `<LUNARC_DATA_ROOT>/processed/` — every pipeline-generated artifact:
  `nace_rev2_classes.{parquet,xlsx}`, `nace_embeddings_{tag}.npz`,
  `io_relatedness.parquet`, `labor_relatedness.parquet`,
  `graph_{nodes,edges,negative_edges}_{name}.parquet`,
  `diffusion_matrix_{name}.npz`.
- `<LUNARC_DATA_ROOT>/embedding/` — trained sentence-transformer checkpoints
  and output embeddings (`train_sentence_embedding.py`'s `OUTPUT_BASE`).
  This consolidates what used to be split across two inconsistent LUNARC
  paths — a plain `DataLatentIndustryRepresentations/` with only an old,
  incomplete `graph_kl` run, and the path the code actually used,
  `.../SCB/DataLatentIndustryRepresentations/` (an erroneous extra `SCB/`
  segment) — onto the single canonical path above.
- `<LUNARC_DATA_ROOT>/archive/` — superseded artifacts: the previously
  git-tracked stale unsuffixed graph/diffusion files and the old MiniLM NACE
  embedding (`archive/metadata_archive/`), and the incomplete pre-
  consolidation `graph_kl` embedding subset
  (`archive/embedding_graph_kl_partial_pre_consolidation/`).

The old `.../SCB/DataLatentIndustryRepresentations/` copy still exists on
disk (not deleted, since nobackup storage has no backup to fall back on) but
nothing reads from it anymore — safe to remove once the new path is
confirmed working end-to-end.
