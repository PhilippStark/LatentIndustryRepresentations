# metadata/

Small reference tables that define what a code means. Nothing here is
generated by the pipeline; data produced or downloaded by the scripts lives
under the data root (`src/latent_industry/common/paths.py`).

- `mapping_Sni_{2,3,4,5}digits_{1992,2002,2007}.json`, `mapping_Sni_section_{1992,2002,2007}.json`
  — SNI code → description per digit level and classification version. The
  descriptions are the node texts of the industry graph
  (`src/latent_industry/graph/nodes.py`) and the input to the text prior.
- `mapping_92_02.csv`, `mapping_02_07.csv` — SCB correspondence tables between
  consecutive SNI versions (the `transition` views and the cross-version
  retrieval evaluation).
- `mapping_Municipality.json` — the 290 municipalities and their names.
- `municipality_crosswalk.json` — year-dependent mapping of historical
  municipality codes to the 290-code universe, formation years of
  municipalities created during 1990–2019, and the handling of invalid codes;
  loaded and validated by `src/latent_industry/common/municipalities.py`.
- `mapping_Kvar.json` — SCB firm-demography (`Kvar`) categories, used to
  identify new firms for the start-up outcome.
